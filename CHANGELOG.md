# Changelog

## 0.3 — Testing release

- Replaced the prototype pages with the four-panel Session Statistics window.
- Added hero switching, a dynamic hero portrait, contextual hints, keyboard closing, and a dialog-view counter.
- Expanded combat tracking with melee and ranged damage, commander damage, killed and lost units, and maximum hits.
- Expanded magic tracking with adventure-map spells, commander casts, spent spell points, average spell damage, and ACM spell upgrades.
- Added land and sea travel, unique object visits, stat objects, chests, artifacts, resource piles, towns, mines, and compatible challenge counters.
- Added player-wide time, economy, conquest, combat, spell, distance, town-recruitment, and external-dwelling recruitment totals.
- Added dwelling-population tracking for normal recruitment and the WoG and HD Mod Buy All functions.
- Added protection against duplicate combat values after a battle replay.
- Added a per-hero battle replay counter to the Combat panel.
- Added right-clicking the adventure-map Quest Log button as a convenient way to open the statistics window.
- Added Russian localization and a dedicated Mod Manager icon.

## 0.2 — Prototype

- Added the first persistent hero and player counters.
- Added the initial statistics overview dialog.
